\# Real or AI



A web-based image classification challenge developed by NSDC MEC.



Participants identify whether each image is AI-generated or real.



\## Tech Stack



\- Next.js

\- TypeScript

\- Prisma

\- Neon PostgreSQL

\- Cloudinary

\- Vercel



\## How It Works



Participants register with their name and email, then identify whether each presented image is Real or AI-generated.



Scoring is time-based, with a maximum of 50 points for a correct answer.



\## Database



The application uses Neon PostgreSQL for storing images and participant scores.



Images are hosted and delivered through Cloudinary.



\## Deployment



The application is deployed using Vercel.
